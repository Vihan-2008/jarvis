Download JARVIS

Free and open source, with no account to create. Pick your system, or run it from source. Every release is on the latest release page.

One download, nothing else to install. The installer brings everything JARVIS needs (its own Python included), asks nothing, and opens JARVIS when it is done. Then type open calculator and press Enter: that is your first command. (Installers up to 0.1.4 still need Python 3.11 on the computer.)

The installers are not code-signed yet. Windows SmartScreen and macOS Gatekeeper warn you the first time you open them. The steps under each download say what to click. If you would rather not, run JARVIS from source instead.

Windows

Everything works on Windows: chat, voice and the wake word, acting on your PC, the tray and its shortcuts, coding agents, artifacts, routines and the security check.

InstallerJARVIS-Setup.exe ZipJARVIS-windows.zip

If SmartScreen warns

  1. Open JARVIS-Setup.exe.
  2. If Windows says it protected your PC, click More info, then Run anyway.
  3. Wait about a minute: it installs for you alone (no administrator rights), adds JARVIS to the Start menu and opens it.
  4. Type open calculator and press Enter.
  5. To remove it later: Settings › Apps › JARVIS, or JARVIS's own Settings › Advanced › Uninstall JARVIS.

macOS New

The app with the wake word, an icon in the menu bar, shortcuts that work from any app, dictation into other apps, working in other apps' windows, step-by-step control and telling the Mac's own sound from your voice. The built-in browser panel and the small listening window are Windows-only for now. Every change is run by automated tests and, on a real Mac at GitHub, by a check that opens TextEdit, types, presses and dictates in it, takes a picture of the screen, presses each shortcut from another app, chooses from the menu-bar menu, plays "Hey Jarvis" to the wake word and measures a sound the Mac plays. Its owner has installed it on a real Mac and opens it from its icon; nobody has used it day to day yet. The installer sets up "Hey JARVIS" (two Python packages and a small model, downloaded while it installs), and macOS asks you to allow Accessibility, Screen Recording and the microphone the first time each is needed.

If Gatekeeper warns

  1. Open JARVIS.dmg (or the unpacked zip). It shows two things: Install JARVIS and Read me first. Double-click Install JARVIS, then click Install. No Terminal window opens.
  2. If macOS says it cannot be opened, click Done, open System Settings, then Privacy & Security, scroll down and click Open Anyway next to "Install JARVIS", then open it again. (On macOS 14 or older, Control-click Install JARVIS and choose Open.) JARVIS is not signed with a paid Apple certificate.
  3. JARVIS opens by itself when it is installed. Type open calculator and press Enter. Next time, open JARVIS from Applications, Launchpad or Spotlight.
  4. To remove it later: JARVIS's Settings › Advanced › Uninstall JARVIS.

What the installer sets up

JARVIS keeps its chats and memory as Markdown notes in a vault, its second brain.

Your notes vault

The installer creates the vault with its folders and starter notes. It never overwrites a note that is already there.

Everything it needs

Its own Python, kept inside its folder, so nothing else on your computer changes. Updates keep your settings, chats and notes, and go back to the version before if a new one does not start.

Your own accounts

JARVIS uses what you already have: the Claude Code and Codex command-line tools signed in with your subscriptions, a Groq key for listening and an ElevenLabs key for its voice. Add the ones you want; keys are kept in the system's key store.

Run from source

No installer and no warnings. You need Git and Python 3.11 or newer; there is nothing to pip install.

Terminal
# get the code
git clone https://github.com/Vihan-2008/jarvis jarvis
cd jarvis

# open JARVIS in its own window
python -m jcc.desktop
  1. Use python3 instead of python if that is how Python is called on your system.
  2. JARVIS runs only on your computer, at 127.0.0.1, and opens in a window of its own.
  3. To update, run git pull in the same folder and open it again.
