Download JARVIS

Free and open source, with no account to create. Pick your system, or run it from source. Every release is on the latest release page.

The installers are not code-signed yet. Windows SmartScreen and macOS Gatekeeper will warn you the first time you open them. The steps under each download say what to click. If you would rather not, run JARVIS from source instead.

Windows

Everything works on Windows: chat, voice and the wake word, acting on your PC, the tray and its shortcuts, coding agents, artifacts, routines and the security check.

InstallerJARVIS-Setup.exe ZipJARVIS-windows.zip

If SmartScreen warns

  1. Open JARVIS-Setup.exe.
  2. If Windows says it protected your PC, click More info, then Run anyway.
  3. Follow the installer's steps.

macOS New

The core app: chat, coding agents, artifacts, routines and the security check. Controlling other apps' windows, the tray and the background wake word are Windows-only for now. The Mac version has been checked by automated tests and has not yet been used day to day on a real Mac.

Disk imageJARVIS.dmg ZipJARVIS-mac.zip

If Gatekeeper warns

  1. Open JARVIS.dmg (or unpack the zip) and double-click Install JARVIS.
  2. If macOS says it cannot check the file, Control-click Install JARVIS, choose Open, then Open again. Or open System Settings, then Privacy & Security, and click Open Anyway.
  3. The installer puts JARVIS in your Applications folder and sets up the notes vault.

What the installer sets up

JARVIS keeps its chats and memory as Markdown notes in a vault, its second brain.

Your notes vault

The installer creates the vault with its folders and starter notes. It never overwrites a note that is already there.

Obsidian, if you want it

The vault is plain Markdown, so any editor works. The installer can install Obsidian to read and edit it, if you choose.

Your own accounts

JARVIS uses what you already have: the Claude Code and Codex command-line tools signed in with your subscriptions, a Groq key for listening and an ElevenLabs key for its voice. Add the ones you want; keys are kept in the system's key store.

Run from source

No installer and no warnings. You need Git and Python 3.11 or newer; there is nothing to pip install.

Terminal
# get the code
git clone https://github.com/Vihan-2008/jarvis jarvis
cd jarvis

# open JARVIS in its own window
python -m jcc.desktop
  1. Use python3 instead of python if that is how Python is called on your system.
  2. JARVIS runs only on your computer, at 127.0.0.1, and opens in a window of its own.
  3. To update, run git pull in the same folder and open it again.
